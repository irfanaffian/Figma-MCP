## Melanjutkan pekerjaan

Baca brief, status, dan riwayat sebagai konteks. Ikuti instruksi pengguna terbaru. Pengguna juga mengedit Figma secara manual, jadi selalu baca kondisi terbaru Desktop - 11 sebelum mengubah apa pun. Jangan menyentuh section yang tidak diminta.

GitHub hanya menyimpan dokumentasi ini. Akses chat, perangkat lain, dan koneksi MCP Figma perlu diverifikasi tersendiri.
