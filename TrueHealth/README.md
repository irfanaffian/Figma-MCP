## Melanjutkan pekerjaan

Baca brief, status, dan riwayat sebagai konteks. Ikuti instruksi pengguna terbaru. Periksa koneksi MCP Figma dan frame yang relevan sebelum mengedit. Fokus pada visual homepage, pertahankan copy asli, dan tunggu instruksi revisi pengguna. Komponen dan design system dibuat setelah visual disetujui.

GitHub menyimpan dokumentasi ini; akses chat, perangkat lain, dan koneksi MCP perlu diverifikasi tersendiri.
